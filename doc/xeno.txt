1. INTRODUCTION                                           *xeno-introduction*

xeno.nvim generates a full colorscheme from a background seed, an accent
seed, and an optional foreground override:
- foreground (shades 50-400, derived from background when omitted)
- background (shades 500-950)
- accent (shades 50-600)

Key features:
- Background-derived foreground palette with optional explicit override
- Highlight overrides with @family.shade syntax
- Plugin highlight integrations
- Terminal integrations including Ghostty
- Window namespace support

2. INSTALLATION                                           *xeno-installation*

Using lazy.nvim: >lua
    {
      'kyza0d/xeno.nvim',
      lazy = false,
      priority = 1000,
      config = function()
        require('xeno').setup({
          background = '#1E1E1E',
          accent = '#8CBE8C',
        })
        vim.cmd('colorscheme xeno')
      end,
    }
<

Using mini.deps: >lua
    local MiniDeps = require('mini.deps')
    MiniDeps.add('kyza0d/xeno.nvim')

    require('xeno').setup({
      background = '#1E1E1E',
      accent = '#8CBE8C',
    })
    vim.cmd('colorscheme xeno')
<

3. USAGE                                                         *xeno-usage*

Basic Setup~
                                                              *xeno.setup()*
>lua
    require('xeno').setup({
      foreground = '#F8F8F2', -- Primary text seed
      background = '#1E1E1E', -- Primary surface seed
      accent = '#8CBE8C',     -- Accent seed
    })
    vim.cmd('colorscheme xeno')
<

Generate Theme Files~
                                                              *xeno.theme()*
>lua
    require('xeno').theme('my-dark-theme', {
      background = '#1E1E1E',
      accent = '#8CBE8C',
    })

    vim.cmd('colorscheme my-dark-theme')
<

4. CONFIGURATION                                         *xeno-configuration*

Configuration Options~

*xeno-config-foreground*
foreground        String. Optional foreground override (hex format). When
                  omitted, foreground shades derive from background.

*xeno-config-background*
background        String. Background seed color (hex format).

*xeno-config-accent*
accent            String. Accent seed color (hex format).

*xeno-config-variation*
variation         Number. Color variation amount (0.0 to 1.0). Default: 0.0

*xeno-config-contrast*
contrast          Number. Contrast adjustment (-1.0 to 1.0). Default: 0.0

*xeno-config-transparent*
transparent       Boolean. Enable transparent background. Default: false

*xeno-config-colors*
Optional semantic overrides:
- red, green, yellow, orange, blue, purple, cyan

*xeno-config-highlights*
highlights        Table. Highlight overrides:
- editor          Table. Editor UI highlights
- syntax          Table. Syntax highlights
- plugins         Table. Plugin-specific overrides

*xeno-config-integrations*
integrations      Table. Integration settings:
- ghostty.enabled       Boolean. Enable Ghostty integration
- ghostty.update_config Boolean. Update Ghostty config file

Example Configuration: >lua
    require('xeno').setup({
      background = '#1E1E1E',
      accent = '#8CBE8C',
      variation = 0.1,
      contrast = 0.05,
      transparent = false,

      red = '#E86671',
      blue = '#7AA2F7',

      highlights = {
        editor = {
          Normal = { bg = '@background.950', fg = '@foreground.50' },
        },
        syntax = {
          Comment = { fg = '@foreground.300', italic = true },
          String = { fg = '@accent.500' },
        },
      },
    })
<

Color Reference Syntax~
                                                       *xeno-color-references*

Use @foreground.XXX, @background.XXX, and @accent.XXX:
- foreground: 50, 100, 200, 300, 400
- background: 500, 600, 700, 800, 900, 950
- accent: 50, 100, 200, 300, 400, 500, 600

Plugin Configuration~
                                                   *xeno-plugin-highlights*

>lua
    highlights = {
      plugins = {
        ["nvim-telescope/telescope.nvim"] = {
          bg = "@background.950",
          fg = "@foreground.50",
          border = "@accent.600",
        },
        ["akinsho/bufferline.nvim"] = {
          selected_bg = "@background.700",
          visible_bg = "@background.900",
          separator = "@background.600",
        },
      },
    }
<

5. API REFERENCE                                                 *xeno-api*

*xeno.setup({config})*
    Initialize xeno with configuration.

*xeno.theme({name}, {config})*
    Generate a colorscheme file.

*xeno.config({config})*
    Set global configuration merged into |xeno.theme()| calls.

*xeno.namespace({name}, {highlights})*
    Create a namespaced variant of the current theme.

*xeno.set_window_namespace({win_id}, {namespace_name})*
    Apply a namespace to a specific window.

*xeno.colors*
    Generated color table (available after |xeno.setup()|).

    Contains: ~
        - foreground_50 through foreground_400
        - background_500 through background_950
        - accent_50 through accent_600
        - red, green, yellow, orange, blue, purple, cyan

6. EXAMPLES                                                   *xeno-examples*

Dark Theme: >lua
    require('xeno').setup({
      background = '#1E1E1E',
      accent = '#8CBE8C',
    })
<

Light Theme: >lua
    require('xeno').setup({
      foreground = '#1E1E1E',
      background = '#FFFFFF',
      accent = '#2E7D32',
    })
<

Generate Multiple Themes: >lua
    local xeno = require('xeno')

    xeno.config({
      transparent = true,
      integrations = { ghostty = { enabled = true } },
    })

    xeno.theme('forest', { foreground = '#F8F8F2', background = '#1E1E1E', accent = '#8CBE8C' })
    xeno.theme('ocean',  { foreground = '#F8F8F2', background = '#1E1E1E', accent = '#7AA2F7' })
    xeno.theme('sunset', { foreground = '#F8F8F2', background = '#1E1E1E', accent = '#FF7A93' })
<

8. TROUBLESHOOTING                                   *xeno-troubleshooting*

Common Issues~

Colors not applying:
- Call `vim.cmd('colorscheme xeno')` after |xeno.setup()|
- Ensure true color support: `:set termguicolors`

Color references not working:
- Use `@family.shade` syntax (for example: `@background.700`)
- Valid ranges:
  - foreground: 50-400
  - background: 500-950
  - accent: 50-600

Theme file not found:
- Call |xeno.theme()| before loading generated colorscheme
